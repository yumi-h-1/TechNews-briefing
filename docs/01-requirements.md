# 01. 제품 요구사항

## 목적

영국·미국·한국에서 일어난 IT·AI 관련 주요 동향을 매일 개인 이메일로 받아본다. LangGraph와 LangSmith를 사용하는 agentic AI 프로젝트로 개발하면서 사용자가 직접 구조와 코드를 이해하고 리뷰한다.

‘동일한 내용’은 세 국가 모두 IT·AI 분야를 다룬다는 의미로 해석한다. 같은 사건을 세 나라 섹션에 반복해서 넣는다는 뜻은 아니다.

## 소스 후보

모두 확정 목록이 아닌 초기 후보이며, 실제 뉴스 품질과 수집 범위로 재평가한다.

| 언어 | 후보 | 초안에서 사용한 피드 |
|---|---|---|
| 영어 | BBC | Technology |
| 영어 | The Guardian | Technology |
| 영어 | CNBC | Technology |
| 영어 | NPR | Technology |
| 한국어 | 연합뉴스 | 산업 |
| 한국어 | 한겨레 | 과학 |
| 한국어 | SBS | 경제 |

한국 추가 검토 후보로 KBS·MBC·경향신문 등이 대화에서 언급됐다. 한국어 주요 언론이라는 조건만 확정됐으며 특정 매체의 정치적 성향이나 선호도는 확인되지 않았다. RSS의 실제 범위와 최신성은 재확인해야 한다. 과학·경제 피드에는 IT와 무관한 기사도 있으므로 별도 선별이 필요하다.

## 개발 전 정리할 미결정 사항

1. **오전 8시의 의미:** 8시에 메일 발송을 시작할지, 8시 도착을 목표로 그 전에 생성할지. 기존 초안은 8시 생성 시작이어서 수 분 뒤 발송될 수 있다.
2. **지역 관련성:** 현지 규제·기업·연구·사건을 중심으로 할지, 글로벌 발표 중 현지 영향이 큰 기사도 넣을지.
3. **메일 분량:** 국가별 최대 3개와 요약 길이가 적절한지.
4. **월 예산과 서비스:** 서버·모델·메일·관측 도구의 총 예산. Render·OpenAI·Resend는 이전 어시스턴트가 고른 초안 옵션이며 사용자가 확정하지 않았다.
5. **장애 정책:** 일부 소스 실패 시 발송할지, 전부 실패한 날은 어떻게 알릴지, 놓친 발송을 언제까지 복구할지.
6. **운영 발신자:** 본인 도메인 사용 여부와 메일 서비스 계정. 수신 이메일만 제공됐고 발송 계정은 제공되지 않았다.

기존 초안의 기본값을 사용자 요구사항으로 둔갑시키지 않는다. 독립적으로 검토할 수 있는 부분은 먼저 설계하고, 위 선택이 실제 구현에 영향을 주는 단계에서 필요한 결정을 받는다.
